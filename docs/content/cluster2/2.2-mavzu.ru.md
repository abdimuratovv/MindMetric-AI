## Сравнения и границы

== означает равенство, != — неравенство, < и > — строгое сравнение. ≤ и ≥ включают равенство. Результат — TRUE или FALSE.

x ← 5 — команда, а x == 5 — вопрос. Условие не должно обновлять переменную. Читайте смысл всего выражения, а не только направление знака.

«Не меньше», «не больше» и «больше» задают разные условия. Проверка самой границы выявляет путаницу между > и ≥.

### Разобранный пример

Выполняется ли требование «балл не меньше 60» при ball = 60?

1. Требование: ball ≥ 60.
2. 60 ≥ 60 истинно.
3. Результат — TRUE.

Ответ: TRUE

### Практика — `cond-compare-practice-1`

x = 8. Какое условие равно TRUE?

- a) x ≥ 8
- b) x > 8
- c) x != 8

Ключ: a

1. Подставьте 8 вместо x.
2. 8 ≥ 8 истинно, остальные условия ложны.

Типичная ошибка: Различайте строгую границу и границу с равенством.

Подсказка: Значение в точности равно границе.

- a: Равенство входит в ≥.
- b: 8 не больше самого себя.
- c: Значения равны.

### Практика — `cond-compare-practice-2`

Каково правильное условие для «возраст не больше 17»?

- a) age < 17
- b) age ≥ 17
- c) age ≤ 17

Ключ: c

1. Не больше означает не превышать.
2. Поэтому age ≤ 17.

Типичная ошибка: Не путайте «не больше» и «не меньше».

Подсказка: Сама граница тоже разрешена.

- a: Это исключает граничный возраст.
- b: Это обращает требование.
- c: Допускаются меньшие и равные значения.

### Входная проверка — `cond-compare-precheck`

Предупреждение нужно, если температура строго ниже нуля. Какое условие подходит?

- a) t > 0
- b) t < 0
- c) t ≤ 0

Ключ: b

1. «Строго ниже» означает сравнение без равенства.
2. Подходит t < 0.

Типичная ошибка: Сохраняйте строгость условия из текста.

- a: Выбирает положительные значения.
- b: Ноль исключён, отрицательные значения включены.
- c: Включает и ноль, расширяя требование.

### Итоговая проверка — `cond-compare-postcheck`

x = 12. Чему равно выражение x != 12?

- a) FALSE
- b) TRUE
- c) x получает новое значение

Ключ: a

1. Проверьте 12 != 12.
2. Значения равны, результат FALSE.

Типичная ошибка: Различайте сравнение и присваивание.

- a: Утверждение о неравенстве одинаковых значений ложно.
- b: != проверяет не равенство, а неравенство.
- c: Сравнение не выполняет присваивание.

## Составные логические условия

AND равно TRUE, когда истинны оба условия; OR — когда истинно хотя бы одно. OR допускает и одновременную истинность обоих. NOT обращает значение.

Интервал задаётся двумя сравнениями: (x ≥ 1) AND (x ≤ 10). Вне интервала: (x < 1) OR (x > 10). Скобки уточняют границы условий.

NOT может относиться ко всему условию. NOT (a AND b) равно (NOT a) OR (NOT b). При отрицании сравнения меняется и включение равенства.

### Разобранный пример

Проверьте (x ≥ 2) AND (x < 5) при x = 4.

1. 4 ≥ 2 — TRUE.
2. 4 < 5 — TRUE.
3. TRUE AND TRUE = TRUE.

Ответ: TRUE

### Практика — `cond-boolean-practice-1`

x = 0. Каков результат (x > 0) OR (x == 0)?

- a) FALSE
- b) Не определён
- c) TRUE

Ключ: c

1. Первая часть FALSE, вторая TRUE.
2. FALSE OR TRUE = TRUE.

Типичная ошибка: Не вычисляйте OR как AND.

Подсказка: Для OR достаточно одной истинной части.

- a: OR не требует истинности обеих частей.
- b: Оба сравнения имеют определённое значение.
- c: Вторая часть истинна, для OR этого достаточно.

### Практика — `cond-boolean-practice-2`

Какое условие принимает значения от 10 до 20 включительно?

- a) (x > 10) AND (x < 20)
- b) (x ≥ 10) AND (x ≤ 20)
- c) (x ≥ 10) OR (x ≤ 20)

Ключ: b

1. Нужны одновременно нижнее и верхнее ограничения.
2. Поскольку границы включены, используются ≥ и ≤.

Типичная ошибка: Для принадлежности интервалу нужен AND.

Подсказка: Значение должно выполнить оба требования.

- a: Границы исключены.
- b: Обе границы выполняются одновременно.
- c: Это принимает и значения вне интервала.

### Входная проверка — `cond-boolean-precheck`

a = TRUE, b = FALSE. Чему равно NOT (a AND b)?

- a) TRUE
- b) FALSE
- c) a получает новое значение

Ключ: a

1. TRUE AND FALSE = FALSE.
2. NOT FALSE = TRUE.

Типичная ошибка: NOT применяется ко всему выражению в скобках.

- a: AND ложно, его отрицание истинно.
- b: Это оставляет результат AND без отрицания.
- c: Выражение не изменяет a.

### Итоговая проверка — `cond-boolean-postcheck`

Доступ: студент или сотрудник, но без блокировки. Какое условие подходит?

- a) student OR (staff AND NOT blocked)
- b) student AND staff AND NOT blocked
- c) (student OR staff) AND NOT blocked

Ключ: c

1. Сначала объедините разрешённые роли через OR.
2. Ко всей группе добавьте требование отсутствия блокировки через AND.

Типичная ошибка: Удаление скобок может изменить смысл допуска.

- a: Это разрешает доступ даже заблокированному студенту.
- b: Это требует одновременно обе роли.
- c: Роль и отсутствие блокировки выполняются вместе.

## if-else и одна ветвь

Если условие if равно TRUE, выполняется первый блок, иначе — else. В этой конструкции выполняется только одна ветвь.

Два независимых if ведут себя иначе: второе условие проверяет значение после первого блока. В ветви else условие повторно не проверяется.

В курсе блоки выделяются { }. Отступы облегчают чтение, но выполняемые действия определяют скобки.

### Разобранный пример

x ← −2; if x < 0 {x ← −x} else {x ← x + 1}. Чему равно конечное x?

1. −2 < 0 истинно.
2. Первый блок делает x равным 2.
3. else не выполняется.

Ответ: 2

### Практика — `cond-if-practice-1`

x ← 7; if x ≥ 5 {x ← x − 2} else {x ← x + 2}. Чему равно конечное x?


Ключ: 5

1. 7 ≥ 5 истинно.
2. x = 7 − 2 = 5; else пропускается.

Типичная ошибка: Не выполняйте обе ветви последовательно.

Подсказка: Проверьте условие по значению до входа в блок.


### Практика — `cond-if-practice-2`

x ← 1; if x < 3 {x ← x + 2}; if x == 3 {x ← x × 4}. Чему равно конечное x?


Ключ: 12

1. Первый независимый if делает x равным 3.
2. Второй if тоже истинен, x = 12.

Типичная ошибка: Не читайте два независимых if как if-else.

Подсказка: Второй if видит новое значение.


### Входная проверка — `cond-if-precheck`

x ← 0; if x > 0 {y ← 10} else {y ← 20}. Чему равно y?


Ключ: 20

1. 0 > 0 ложно.
2. else присваивает y значение 20.

Типичная ошибка: Не считайте ноль положительным.


### Итоговая проверка — `cond-if-postcheck`

x ← 4; if x < 5 {x ← x + 3} else {x ← x − 3}; OUTPUT x. Каков выход?


Ключ: 7

1. Исходное 4 выполняет условие, x = 7.
2. Новое значение не запускает else, вывод равен 7.

Типичная ошибка: Не переходите в else из-за значения после первого блока.


## Вложенные и многоветвевые условия

В цепочке if ... else if ... else выполняется первая истинная ветвь, остальные пропускаются. Если общее условие стоит первым, до более узкого можно не дойти.

Для категорий балла удобно сначала проверить верхнюю: ball ≥ 90, затем ball ≥ 60, в конце остальные случаи. Проверяйте границы по таблице.

Во вложенном условии внутренний if выполняется только после входа во внешний блок. Если внешнее условие ложно, внутренней проверки вообще не будет.

### Разобранный пример

ball = 95; if ball ≥ 90 {r ← 3} else if ball ≥ 60 {r ← 2} else {r ← 1}. Чему равно r?

1. Первое условие истинно.
2. r = 3.
3. Следующие условия не выполняются.

Ответ: 3

### Практика — `cond-multiple-practice-1`

ball = 75; if ball ≥ 90 {r ← 3} else if ball ≥ 60 {r ← 2} else {r ← 1}. Чему равно r?


Ключ: 2

1. 75 ≥ 90 ложно.
2. 75 ≥ 60 истинно, r = 2.

Типичная ошибка: Вычисляйте условия по порядку.

Подсказка: Цепочка останавливается на первом истинном условии.


### Практика — `cond-multiple-practice-2`

a = 5, b = −1; r ← 0; if a > 0 {if b > 0 {r ← 1} else {r ← 2}} else {r ← 3}. Чему равно r?


Ключ: 2

1. Внешнее условие истинно, открывается внутренний блок.
2. b > 0 ложно, внутренний else делает r = 2.

Типичная ошибка: Не путайте внутренний и внешний else.

Подсказка: По скобкам определите, к какому if относится каждый else.


### Входная проверка — `cond-multiple-precheck`

ball = 90; if ball ≥ 90 {r ← 3} else if ball ≥ 60 {r ← 2} else {r ← 1}. Чему равно r?


Ключ: 3

1. 90 входит в верхнюю категорию.
2. Первая ветвь даёт r = 3.

Типичная ошибка: Не относите границу к нижней категории.


### Итоговая проверка — `cond-multiple-postcheck`

Верхняя категория: ball ≥ 90. Код сначала проверяет if ball ≥ 60, затем else if ball ≥ 90. В чём проблема?

- a) Высокий балл попадает в первую ветвь, верхняя категория недостижима
- b) Все условия всегда ложны
- c) Выполняются обе ветви

Ключ: a

1. Высокий балл также превышает нижнюю границу.
2. После выбора первой ветви цепочка пропускает остальные.

Типичная ошибка: Проверяйте порядок узких и общих условий.

- a: Узкое условие оказалось после общего.
- b: Высокий балл выполняет первое условие.
- c: Цепочка else if выполняет только одну ветвь.

## switch-case и полнота обработки

В курсе switch mode {case ...; default ...} сравнивает одно значение с точными вариантами. Выполняется только совпавший case; автоматического перехода к следующему case нет.

default выполняется, когда ни один case не подошёл. Это правило псевдокода; в реальном языке, например в switch стиля C, отдельно проверяют break и другие правила.

Для интервала, нескольких переменных или сложной логики if часто понятнее. Точные дискретные значения, например коды меню, подходят для switch.

### Разобранный пример

mode = 2; switch mode {case 1: r ← 10; case 2: r ← 20; default: r ← 0}. Чему равно r?

1. mode совпадает со вторым case.
2. Выполняется только r ← 20.
3. default не выполняется.

Ответ: 20

### Практика — `cond-switch-practice-1`

mode = 9; switch mode {case 1: r ← 10; case 2: r ← 20; default: r ← −1}. Чему равно r?


Ключ: -1

1. 9 не равно ни одному из заданных case.
2. default даёт r = −1.

Типичная ошибка: Не подбирайте приблизительно существующий case для неизвестного значения.

Подсказка: При отсутствии точного совпадения берётся default.


### Практика — `cond-switch-practice-2`

Какой способ понятнее для условия «x положительно И y отрицательно»?

- a) default для любого входа
- b) if (x > 0) AND (y < 0)
- c) В switch x только case 1

Ключ: b

1. Условие не является равенством одному точному значению.
2. if объединяет два сравнения через AND.

Типичная ошибка: Не подставляйте switch вместо любого условия.

Подсказка: Здесь проверяется не один код, а два признака.

- a: Это не проверяет нужное условие.
- b: Логика по двум переменным записана непосредственно.
- c: Это не охватывает все положительные значения и y.

### Входная проверка — `cond-switch-precheck`

code = 1; switch code {case 1: r ← 4; case 2: r ← 8; default: r ← 0}. Чему равно r по правилам курса?


Ключ: 4

1. Совпадает первый case.
2. Перехода к следующему case нет, r = 4.

Типичная ошибка: Не переносите правило fall-through другого языка в этот псевдокод.


### Итоговая проверка — `cond-switch-postcheck`

Меню принимает только коды OPEN и SAVE. Для другого кода тоже нужно сообщение. Что добавить?

- a) Считать неизвестный код SAVE
- b) Ещё раз повторить OPEN
- c) Сообщение о неизвестном коде в default

Ключ: c

1. Известные варианты — отдельные case.
2. Остальные входы получают понятное сообщение через default.

Типичная ошибка: Не игнорируйте неизвестный вход и не превращайте его в другое действие.

- a: Это может запустить неверное действие.
- b: Повтор case не охватывает неизвестное значение.
- c: Несовпавшие значения обрабатываются явно.
