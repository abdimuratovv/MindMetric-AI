# 2.3 — Takrorlash operatorlari va rekursiya

O‘quv resursi · draft · versiya 1

[Psevdokod qoidalari](pseudocode.uz.md) · [Barcha mavzular](README.md)

Mualliflik topshiriqlari. Ushbu o‘qituvchi nusxasida javoblar va yechimlar bor; tekshiruv paytida fayl talabaga to‘liq berilmaydi.

## for va takrorlanish chegaralari

Kursda for i ← a TO b {amal} butun i ni a dan b gacha oshirib yuradi; ikkala chegara kiritiladi. a > b bo‘lsa tana bajarilmaydi. Bu Python range qoidasidan farq qiladi.

Hisoblagich iteratsiya qiymatini, jamlagich esa umumiy natijani saqlaydi. Yig‘indi uchun s ← 0 sikldan oldin yoziladi; tanada s ← s + i yangilanadi.

Jamlagichni har aylanishda nol qilish avvalgi yig‘indini yo‘qotadi. Tana necha marta bajarilishini va har safar qaysi qiymat bilan ishlashini alohida kuzating.

### Ishlangan misol

s ← 0; for i ← 1 TO 4 {s ← s + i}. s?

1. i qiymatlari 1, 2, 3, 4.
2. s qiymatlari 1, 3, 6, 10.
3. Oxirgi yig‘indi 10.

Javob: 10

### Mashq — `loop-for-practice-1`

s ← 0; for i ← 2 TO 5 {s ← s + i}. s?


Kalit: 14

1. Ikkala chegara kiradi.
2. 2 + 3 + 4 + 5 = 14.

Keng tarqalgan xato: Oxirgi chegarani tashlab ketmang.

Ishora: Avval barcha i qiymatlarini yozing.


### Mashq — `loop-for-practice-2`

p ← 1; for i ← 1 TO 3 {p ← p × 2}. p?


Kalit: 8

1. Tana 3 marta bajariladi.
2. p: 2, 4, 8.

Keng tarqalgan xato: Ko‘paytirish sonini i qiymatlari yig‘indisi bilan aralashtirmang.

Ishora: Har safar avvalgi p ikki baravar bo‘ladi.


### Boshlang‘ich tekshiruv — `loop-for-precheck`

c ← 0; for i ← 3 TO 7 {c ← c + 1}. c?


Kalit: 5

1. Qiymatlar 3, 4, 5, 6, 7.
2. Ular 5 ta, demak c = 5.

Keng tarqalgan xato: Takrorlar soni oxirgi i qiymatiga teng bo‘lishi shart emas.


### Yakuniy tekshiruv — `loop-for-postcheck`

s ← 9; for i ← 5 TO 3 {s ← s + i}. Kurs qoidasi bo‘yicha s?


Kalit: 9

1. Boshlanish tugashdan katta.
2. O‘suvchi for tanasi bajarilmaydi, s = 9.

Keng tarqalgan xato: TO yashirin kamayish qadamini bildirmaydi.


## while va tugash sharti

while shartni tanadan oldin tekshiradi. Dastlab FALSE bo‘lsa tana bir marta ham bajarilmaydi. Har aylanishdan keyin shart qayta tekshiriladi.

Sikl holati shartni bir kuni FALSE qiladigan tomonga o‘zgarishi kerak. i ← i + 1 yoki qoldiqni kamaytirish kabi qadamning yo‘qligi cheksiz siklga olib kelishi mumkin.

Tugashni taxmin qilish o‘rniga nima kamayishi yoki chegaraga yaqinlashishini ayting. Shartdagi va yangilanishdagi belgilar bir-biriga mos bo‘lsin.

### Ishlangan misol

x ← 1; while x < 8 {x ← x × 2}. Oxirgi x?

1. x: 1 → 2 → 4 → 8.
2. 8 < 8 yolg‘on.
3. Tana qayta bajarilmaydi, x = 8.

Javob: 8

### Mashq — `loop-while-practice-1`

x ← 3; c ← 0; while x < 12 {x ← x + 3; c ← c + 1}. c?


Kalit: 3

1. Tana x boshlanishlari 3, 6, 9 da ishlaydi.
2. x = 12 da to‘xtaydi, c = 3.

Keng tarqalgan xato: To‘xtashdagi tekshiruvni yana bitta tana deb sanamang.

Ishora: Shart har gal tanadan oldin tekshiriladi.


### Mashq — `loop-while-practice-2`

i ← 0; while i < 4 {OUTPUT i}. Nima yetishmayapti?

- a) OUTPUT ni ko‘paytirish
- b) Tanada i ni chegaraga yaqinlashtiruvchi yangilanish
- c) Har safar i ← 0 qilish

Kalit: b

1. i qiymati tanada o‘zgarmayapti.
2. Masalan, i ← i + 1 tugashga olib boradi.

Keng tarqalgan xato: OUTPUTni holat yangilanishi deb hisoblamang.

Ishora: Shartni yolg‘on qiladigan qiymatga qanday yetiladi?

- a: Chiqarish i ni o‘zgartirmaydi.
- b: i o‘zgarmasa shart doim rost qoladi.
- c: Bu holatni boshlanishga qaytarib, tugashga yordam bermaydi.

### Boshlang‘ich tekshiruv — `loop-while-precheck`

x ← 10; c ← 0; while x < 5 {c ← c + 1; x ← x + 1}. c?


Kalit: 0

1. Dastlab 10 < 5 yolg‘on.
2. Tana bajarilmaydi, c = 0.

Keng tarqalgan xato: while kamida bir marta ishlaydi degan taxmin noto‘g‘ri.


### Yakuniy tekshiruv — `loop-while-postcheck`

x ← 20; c ← 0; while x > 2 {x ← x div 2; c ← c + 1}. c?


Kalit: 3

1. Butun bo‘linish: 20 → 10 → 5 → 2.
2. 2 > 2 yolg‘on, c = 3.

Keng tarqalgan xato: div kasr qismini tashlaydi; oddiy bo‘lish bilan almashtirmang.


## do-while: avval tana, keyin shart

do {tana} while shart tanani avval bajaradi, keyin shart TRUE bo‘lsa takrorlaydi. Shuning uchun tana kamida bir marta bajariladi.

Bu yozuv repeat-until emas: while sharti rost bo‘lsa DAVOM etadi. Shartning ma’nosini teskarilash xatoga olib keladi.

Menyu yoki birinchi urinish majburiy bo‘lgan jarayonga mos. Kirishning yaroqliligini baribir tekshirish kerak; kamida bir marta bajarilishi xavfsizlik tekshiruvi o‘rnini bosmaydi.

### Ishlangan misol

x ← 5; do {x ← x + 1} while x < 3. Oxirgi x?

1. Tana avval x ni 6 qiladi.
2. 6 < 3 yolg‘on.
3. Takror yo‘q, x = 6.

Javob: 6

### Mashq — `loop-do-practice-1`

x ← 0; do {x ← x + 2} while x < 5. Oxirgi x?


Kalit: 6

1. Tanadan keyingi qiymatlar 2, 4, 6.
2. 6 < 5 yolg‘on, x = 6.

Keng tarqalgan xato: Chegaraga yetishdan oldingi qiymatda to‘xtatmang.

Ishora: Shartni yangilangan qiymatda tekshiring.


### Mashq — `loop-do-practice-2`

c ← 0; do {c ← c + 1} while FALSE. c?


Kalit: 1

1. Birinchi tana shartsiz bajariladi.
2. FALSE takrorni to‘xtatadi, c = 1.

Keng tarqalgan xato: Boshlang‘ich shartni tanadan oldin qo‘ymang.

Ishora: do-while ning birinchi qadami tana.


### Boshlang‘ich tekshiruv — `loop-do-precheck`

x ← 9; do {x ← x − 4} while x > 3. Oxirgi x?


Kalit: 1

1. Avval x = 5, shart rost.
2. Keyin x = 1, shart yolg‘on.

Keng tarqalgan xato: do-while shart rostligida tugamaydi, davom etadi.


### Yakuniy tekshiruv — `loop-do-postcheck`

Dastlab shart FALSE. while va do-while tanalari necha marta bajariladi? Shart tanada ham FALSE qoladi.

- a) Ikkalasi: 1
- b) while: 0; do-while: 1
- c) Ikkalasi: 0

Kalit: b

1. while oldindan tekshiradi.
2. do-while birinchi tanadan keyin tekshiradi.

Keng tarqalgan xato: Nomiga emas, tekshirish joyiga qarang.

- a: while yolg‘on boshlang‘ich shartda kirmaydi.
- b: Tekshirish joylari farq qiladi.
- c: do-while dastlab tanani bajaradi.

## Ichma-ich sikllarni kuzatish

Tashqi siklning har bir aylanishida ichki sikl qaytadan boshlanadi. Mustaqil chegaralarda umumiy tana soni tashqi va ichki takrorlar ko‘paytmasidir.

for i ← 1 TO 2 {for j ← 1 TO 3 {...}} juftlari qatorlab yuradi. Juftlar sonini takrorlar sonlarini qo‘shib hisoblamang.

Ichki chegara i ga bog‘liq bo‘lsa ko‘paytma yetmaydi: har tashqi qiymatdagi ichki takrorni alohida sanang. Uchburchak shakldagi ish 1 + 2 + ... bo‘lishi mumkin.

### Ishlangan misol

c ← 0; for i ← 1 TO 2 {for j ← 1 TO 3 {c ← c + 1}}. c?

1. Tashqi sikl 2 marta.
2. Har safar ichki sikl 3 marta.
3. c = 2 × 3 = 6.

Javob: 6

### Mashq — `loop-nested-practice-1`

c ← 0; for i ← 1 TO 3 {for j ← 1 TO 4 {c ← c + 1}}. c?


Kalit: 12

1. Har tashqi aylanishda 4 ichki aylanish.
2. 3 × 4 = 12.

Keng tarqalgan xato: Takrorlar sonini qo‘shmang.

Ishora: Har tashqi qiymat uchun ichki sikl yangidan yuradi.


### Mashq — `loop-nested-practice-2`

c ← 0; for i ← 1 TO 3 {for j ← 1 TO i {c ← c + 1}}. c?


Kalit: 6

1. Ichki takrorlar mos ravishda 1, 2, 3.
2. 1 + 2 + 3 = 6.

Keng tarqalgan xato: Bog‘liq chegarada bir xil ichki uzunlikni olmang.

Ishora: Har i uchun j chegarasini alohida yozing.


### Boshlang‘ich tekshiruv — `loop-nested-precheck`

s ← 0; for i ← 1 TO 2 {for j ← 1 TO 3 {s ← s + i}}. s?


Kalit: 9

1. i = 1 da 1 uch marta, i = 2 da 2 uch marta qo‘shiladi.
2. 3 + 6 = 9.

Keng tarqalgan xato: Tana sanog‘i bilan jamlanayotgan qiymat bir xil emas.


### Yakuniy tekshiruv — `loop-nested-postcheck`

c ← 0; for i ← 1 TO 4 {for j ← 1 TO i {c ← c + 1}}. c?


Kalit: 10

1. Ichki takrorlar 1, 2, 3, 4.
2. Yig‘indi 10.

Keng tarqalgan xato: Ichki chegaraning tashqi hisoblagichga bog‘liqligini saqlang.


## Rekursiya va tayanch holat

Rekursiv funksiya o‘zini kichikroq masala bilan chaqiradi. Tayanch holat bevosita javob qaytarib, yangi chaqiruv qilmaydi.

S(n): if n == 0 {RETURN 0} else {RETURN n + S(n − 1)}, n manfiy bo‘lmagan butun. Har chaqiruv argumentni kamaytirib tayanch holatga olib boradi.

Chaqiruvlar avval chuqurlashadi, javoblar esa orqaga qaytadi. Rekursiya bepul emas: tugallanmagan chaqiruvlar stekda joy oladi. Yetarli bo‘lmagan tayanch yoki noto‘g‘ri yo‘nalish tugamaslikka olib keladi.

### Ishlangan misol

S(3) ni yuqoridagi qoida bilan toping.

1. S(3) = 3 + S(2), S(2) = 2 + S(1).
2. S(1) = 1 + S(0), S(0) = 0.
3. Orqaga qaytib: 1, 3, 6.

Javob: 6

### Mashq — `loop-recursion-practice-1`

F(0) = 1; n > 0 da F(n) = n × F(n − 1). F(4)?


Kalit: 24

1. F(4) = 4 × 3 × 2 × 1 × F(0).
2. F(0) = 1, natija 24.

Keng tarqalgan xato: Ko‘paytmaning tayanchini nol qilmang.

Ishora: Chaqiruvni tayanch holatgacha yozib chiqing.


### Mashq — `loop-recursion-practice-2`

n ≥ 0 uchun G(n) faqat G(n + 1) ni chaqiradi, tayanch esa n == 0. n > 0 da muammo?

- a) Tayanch borligi o‘zi yetarli
- b) Argument tayanchdan uzoqlashadi
- c) Rekursiya avtomatik kamaytiradi

Kalit: b

1. n + 1 musbat argumentni oshiradi.
2. Tayanchga yetish yo‘li yo‘q, yo‘nalish tuzatilishi kerak.

Keng tarqalgan xato: Tayanchni yozish bilan birga unga yetishni isbotlang.

Ishora: Har chaqiruvda argument tayanchga yaqinlashyaptimi?

- a: Unga yetish ham zarur.
- b: Musbat qiymat oshib nolga yetmaydi.
- c: O‘zgarish aynan yozilgan ifodaga bog‘liq.

### Boshlang‘ich tekshiruv — `loop-recursion-precheck`

H(0) = 2; n > 0 da H(n) = H(n − 1) + 3. H(3)?


Kalit: 11

1. H(1) = 5, H(2) = 8.
2. H(3) = 11.

Keng tarqalgan xato: Boshlang‘ich tayanch qiymatni yo‘qotmang.


### Yakuniy tekshiruv — `loop-recursion-postcheck`

R(0) = 0; n > 0 da R(n) faqat R(n − 1) ni bir marta chaqiradi. R(4) hisobida tayanch bilan jami nechta funksiya chaqiruvi bor?


Kalit: 5

1. Argumentlar 4, 3, 2, 1, 0.
2. Boshlang‘ich va tayanch bilan 5 chaqiruv.

Keng tarqalgan xato: Faqat rekursiv o‘tishlarni sanab, dastlabki chaqiruvni unutmang.
