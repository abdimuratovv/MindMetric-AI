# Справочник псевдокода для 2-го кластера

Запись курса не предназначена для запуска в конкретном языке программирования. Для чтения кода и трассировки значений действуют следующие правила.

| Запись | Значение |
|---|---|
| `x ← выражение` | Вычислить правую часть по текущим значениям и записать в x |
| `==`, `!=`, `<`, `>`, `≤`, `≥` | Сравнение; не присваивает значение переменной |
| `TRUE`, `FALSE` | Логические истина и ложь |
| `AND`, `OR`, `NOT` | Оба условия; хотя бы одно; отрицание. OR включает одновременную истинность обоих |
| `{ ... }` | Тело одной управляющей конструкции; вложенные скобки задают свой блок |
| `;` | Разделитель последовательных команд |
| `INPUT x`, `OUTPUT x` | Ввод и вывод; OUTPUT не меняет значение |
| `RETURN выражение` | Вернуть результат функции и завершить этот вызов |
| `if условие {...} else {...}` | Выполняется только одна ветвь |
| `else if` | Выбирается первое истинное условие; последующие пропускаются |
| `switch x {case значение: ...; default: ...}` | Один точно совпавший case, иначе default; автоматического перехода к следующему case нет |
| `for i ← a TO b {...}` | Целые значения от a до b с шагом 1, обе границы включены; при a > b тело не выполняется |
| `while условие {...}` | Условие проверяется заранее; тело может выполниться ноль раз |
| `do {...} while условие` | Сначала выполняется тело; при TRUE повторяется, при FALSE завершается |
| `a div b`, `a mod b` | В этих ресурсах a — неотрицательное целое, b — положительное целое: целая часть частного и остаток |

В арифметике действуют приоритеты скобок, умножения/деления, сложения/вычитания. При одинаковом приоритете вычисление идёт слева направо. Логические условия записываются со скобками. Если в вопросе не сказано иначе, используется точная арифметика больших целых без учёта переполнения; в реальном языке нужно проверять тип числа и диапазон.

**Различие языков:** `for ... TO` включает верхнюю границу; Python `range` её исключает. `switch` курса не переходит к следующей ветви; в других языках правила отличаются. При переводе операторы, имена переменных и константы не меняются. Область входа вроде `n ≥ 0` обязательна и для рекурсии.

**Блок-схемы:** овал — START/END; параллелограмм — INPUT/OUTPUT; прямоугольник — действие; ромб — DECISION. Из условия выходят ветви TRUE/FALSE. В текстовой схеме отдельно указаны каждый путь и завершение; смысл не зависит только от формы или цвета.
