# 2.2 — Shart va taqqoslash operatorlari

O‘quv resursi · draft · versiya 1

[Psevdokod qoidalari](pseudocode.uz.md) · [Barcha mavzular](README.md)

Mualliflik topshiriqlari. Ushbu o‘qituvchi nusxasida javoblar va yechimlar bor; tekshiruv paytida fayl talabaga to‘liq berilmaydi.

## Taqqoslash va chegaralar

== tenglikni, != teng emaslikni, < va > qat’iy taqqoslashni bildiradi. ≤ va ≥ tenglikni ham qamraydi. Natija TRUE yoki FALSE bo‘ladi.

x ← 5 buyruq, x == 5 esa savol. Shart o‘zgaruvchini yangilamasligi kerak. Belgining yo‘nalishini emas, butun gapning ma’nosini o‘qing.

“Kamida”, “ko‘pi bilan” va “dan katta” turli shartlar. Chegaraning o‘zini tekshirish > bilan ≥ xatosini aniqlaydi.

### Ishlangan misol

“Ball kamida 60” talabi ball = 60 da bajariladimi?

1. Talab ball ≥ 60.
2. 60 ≥ 60 rost.
3. Natija TRUE.

Javob: TRUE

### Mashq — `cond-compare-practice-1`

x = 8. Qaysi shart TRUE?

- a) x ≥ 8
- b) x > 8
- c) x != 8

Kalit: a

1. x o‘rniga 8 qo‘ying.
2. 8 ≥ 8 rost, qolgan shartlar yolg‘on.

Keng tarqalgan xato: Qat’iy va tenglikli chegarani farqlang.

Ishora: Qiymat aynan chegaraga teng.

- a: Tenglik ≥ ga kiradi.
- b: 8 o‘zidan katta emas.
- c: Qiymatlar teng.

### Mashq — `cond-compare-practice-2`

“Yosh ko‘pi bilan 17” uchun to‘g‘ri shart?

- a) age < 17
- b) age ≥ 17
- c) age ≤ 17

Kalit: c

1. Ko‘pi bilan — oshmasin degani.
2. Shuning uchun age ≤ 17.

Keng tarqalgan xato: “Ko‘pi bilan”ni “kamida” bilan almashtirmang.

Ishora: Chegaraning o‘zi ham ruxsat etilgan.

- a: Bu chegara yoshni chiqarib tashlaydi.
- b: Bu talabni teskari qiladi.
- c: Kichik va teng qiymatlar qabul qilinadi.

### Boshlang‘ich tekshiruv — `cond-compare-precheck`

Harorat noldan qat’iy past bo‘lsa ogohlantirish kerak. Qaysi shart mos?

- a) t > 0
- b) t < 0
- c) t ≤ 0

Kalit: b

1. “Qat’iy past” tengliksiz taqqoslash.
2. Mos yozuv t < 0.

Keng tarqalgan xato: Matndagi qat’iylikni saqlang.

- a: Musbat qiymatlarni tanlaydi.
- b: Nol kiritilmaydi, manfiylar kiritiladi.
- c: Nolni ham qamrab, talabni kengaytiradi.

### Yakuniy tekshiruv — `cond-compare-postcheck`

x = 12. x != 12 ifodasining qiymati?

- a) FALSE
- b) TRUE
- c) x yangi qiymat oladi

Kalit: a

1. 12 != 12 ni tekshiring.
2. Qiymatlar teng, natija FALSE.

Keng tarqalgan xato: Taqqoslash bilan qiymat berishni farqlang.

- a: Bir xil qiymatlar teng emas degan gap yolg‘on.
- b: != tenglikni emas, teng emaslikni so‘raydi.
- c: Taqqoslash qiymat bermaydi.

## Murakkab mantiqiy shartlar

AND ikkala shart rost bo‘lsa, OR kamida biri rost bo‘lsa TRUE bo‘ladi. OR ikkisi ham rost bo‘lishiga ham ruxsat beradi. NOT qiymatni teskarilaydi.

Oraliqni ikkita taqqoslash bilan yozing: (x ≥ 1) AND (x ≤ 10). Tashqarida bo‘lish: (x < 1) OR (x > 10). Qavslar shart chegarasini aniq qiladi.

NOT butun shartga taalluqli bo‘lishi mumkin. NOT (a AND b) ifodasi (NOT a) OR (NOT b) ga teng. Inkor qilganda taqqoslashning tenglik chegarasi ham o‘zgaradi.

### Ishlangan misol

x = 4 uchun (x ≥ 2) AND (x < 5) ni tekshiring.

1. 4 ≥ 2 — TRUE.
2. 4 < 5 — TRUE.
3. TRUE AND TRUE = TRUE.

Javob: TRUE

### Mashq — `cond-boolean-practice-1`

x = 0. (x > 0) OR (x == 0) natijasi?

- a) FALSE
- b) Aniqlanmagan
- c) TRUE

Kalit: c

1. Birinchi qism FALSE, ikkinchisi TRUE.
2. FALSE OR TRUE = TRUE.

Keng tarqalgan xato: OR ni AND kabi baholamang.

Ishora: OR uchun kamida bitta rost qism yetadi.

- a: OR ikkala qismni rost bo‘lishini talab qilmaydi.
- b: Ikkala taqqoslash ham aniq qiymatga ega.
- c: Ikkinchi qism rost, OR uchun yetarli.

### Mashq — `cond-boolean-practice-2`

Qaysi shart 10 dan 20 gacha, ikkala chekkasi bilan, qiymatni qabul qiladi?

- a) (x > 10) AND (x < 20)
- b) (x ≥ 10) AND (x ≤ 20)
- c) (x ≥ 10) OR (x ≤ 20)

Kalit: b

1. Pastdan va yuqoridan cheklov birga kerak.
2. Chegaralar kiritilgani uchun ≥ va ≤ olinadi.

Keng tarqalgan xato: Oraliq ichida bo‘lish uchun AND kerak.

Ishora: Qiymat ikkala talabni ham bajarishi kerak.

- a: Chegaralar chiqarib tashlangan.
- b: Ikkala chegara bir vaqtda bajariladi.
- c: Bu oraliq tashqarisidagi qiymatlarni ham qabul qiladi.

### Boshlang‘ich tekshiruv — `cond-boolean-precheck`

a = TRUE, b = FALSE. NOT (a AND b) qiymati?

- a) TRUE
- b) FALSE
- c) a yangi qiymat oladi

Kalit: a

1. TRUE AND FALSE = FALSE.
2. NOT FALSE = TRUE.

Keng tarqalgan xato: NOT qavs ichidagi butun ifodaga qo‘llanadi.

- a: AND yolg‘on, inkori rost.
- b: Bu AND natijasini inkorsiz qoldiradi.
- c: Ifoda a ni o‘zgartirmaydi.

### Yakuniy tekshiruv — `cond-boolean-postcheck`

Ruxsat: talaba yoki xodim, lekin bloklanmagan. Qaysi shart mos?

- a) student OR (staff AND NOT blocked)
- b) student AND staff AND NOT blocked
- c) (student OR staff) AND NOT blocked

Kalit: c

1. Avval ruxsatli rollarni OR bilan birlashtiring.
2. Butun guruhga bloklanmaganlik talabini AND bilan qo‘shing.

Keng tarqalgan xato: Qavs olib tashlansa ruxsat ma’nosi o‘zgarishi mumkin.

- a: Bu bloklangan talabaga ham ruxsat beradi.
- b: Bir vaqtning o‘zida ikkala rolni talab qiladi.
- c: Rol va bloklanmaganlik birga bajariladi.

## if-else va bitta tarmoq

if sharti TRUE bo‘lsa birinchi blok, aks holda else bajariladi. Shu konstruksiyaning faqat bitta tarmog‘i ishlaydi.

Mustaqil ikkita if boshqa xulq beradi: ikkinchi shart birinchi blokdan keyingi qiymatni tekshiradi. if-else ikkinchi tarmog‘ida shart qayta tekshirilmaydi.

Kursda bloklar { } bilan ajratiladi. Chekinish o‘qishni osonlashtiradi, ammo bajariladigan amallarni qavslar belgilaydi.

### Ishlangan misol

x ← −2; if x < 0 {x ← −x} else {x ← x + 1}. Oxirgi x?

1. −2 < 0 rost.
2. Birinchi blok x ni 2 qiladi.
3. else bajarilmaydi.

Javob: 2

### Mashq — `cond-if-practice-1`

x ← 7; if x ≥ 5 {x ← x − 2} else {x ← x + 2}. Oxirgi x?


Kalit: 5

1. 7 ≥ 5 rost.
2. x = 7 − 2 = 5; else tashlanadi.

Keng tarqalgan xato: Ikkala tarmoqni ketma-ket bajarmang.

Ishora: Shartni blokka kirishdan oldingi qiymatda tekshiring.


### Mashq — `cond-if-practice-2`

x ← 1; if x < 3 {x ← x + 2}; if x == 3 {x ← x × 4}. Oxirgi x?


Kalit: 12

1. Birinchi mustaqil if x ni 3 qiladi.
2. Ikkinchi if ham rost, x = 12.

Keng tarqalgan xato: Ikki mustaqil if ni if-else deb o‘qimang.

Ishora: Ikkinchi if yangi qiymatni ko‘radi.


### Boshlang‘ich tekshiruv — `cond-if-precheck`

x ← 0; if x > 0 {y ← 10} else {y ← 20}. y qiymati?


Kalit: 20

1. 0 > 0 yolg‘on.
2. else y ga 20 beradi.

Keng tarqalgan xato: Nolni musbat deb hisoblamang.


### Yakuniy tekshiruv — `cond-if-postcheck`

x ← 4; if x < 5 {x ← x + 3} else {x ← x − 3}; OUTPUT x. Chiqish?


Kalit: 7

1. Boshlang‘ich 4 shartni bajaradi, x = 7.
2. Yangi qiymat else ni ishga tushirmaydi, chiqish 7.

Keng tarqalgan xato: Blokdan keyingi qiymat sabab else ga o‘tib ketmang.


## Ichma-ich va ko‘p tarmoqli shart

if ... else if ... else zanjirida birinchi rost tarmoq bajarilib, qolganlari tashlanadi. Umumiy shart avval tursa, torroq shartga navbat kelmasligi mumkin.

Ball bo‘yicha yuqori toifani avval tekshirish qulay: ball ≥ 90, keyin ball ≥ 60, oxirida qolgan holat. Chegaralarni jadval qilib tekshiring.

Ichma-ich shartda ichki if faqat tashqi blok ochilsa bajariladi. Tashqi shart yolg‘on bo‘lsa ichki tekshiruvga umuman kirilmaydi.

### Ishlangan misol

ball = 95; if ball ≥ 90 {r ← 3} else if ball ≥ 60 {r ← 2} else {r ← 1}. r?

1. Birinchi shart rost.
2. r = 3.
3. Keyingi shartlar bajarilmaydi.

Javob: 3

### Mashq — `cond-multiple-practice-1`

ball = 75; if ball ≥ 90 {r ← 3} else if ball ≥ 60 {r ← 2} else {r ← 1}. r?


Kalit: 2

1. 75 ≥ 90 yolg‘on.
2. 75 ≥ 60 rost, r = 2.

Keng tarqalgan xato: Shartlarni tartib bilan baholang.

Ishora: Birinchi rost shartda zanjir to‘xtaydi.


### Mashq — `cond-multiple-practice-2`

a = 5, b = −1; r ← 0; if a > 0 {if b > 0 {r ← 1} else {r ← 2}} else {r ← 3}. r?


Kalit: 2

1. Tashqi shart rost, ichki blok ochiladi.
2. b > 0 yolg‘on, ichki else r = 2 qiladi.

Keng tarqalgan xato: Ichki va tashqi else ni aralashtirmang.

Ishora: Har else qaysi if ga tegishli ekanini qavsdan toping.


### Boshlang‘ich tekshiruv — `cond-multiple-precheck`

ball = 90; if ball ≥ 90 {r ← 3} else if ball ≥ 60 {r ← 2} else {r ← 1}. r?


Kalit: 3

1. 90 yuqori chegaraga kiradi.
2. Birinchi tarmoq r = 3 beradi.

Keng tarqalgan xato: Chegarani pastki toifaga tushirmang.


### Yakuniy tekshiruv — `cond-multiple-postcheck`

Yuqori toifa ball ≥ 90. Kod avval if ball ≥ 60, keyin else if ball ≥ 90 ni tekshiradi. Muammo nima?

- a) Yuqori ball birinchi tarmoqqa kirib, yuqori toifa ochilmaydi
- b) Barcha shartlar doim yolg‘on
- c) Har ikkala tarmoq bajariladi

Kalit: a

1. Yuqori ball quyi chegaradan ham katta.
2. Birinchi tarmoq tanlangach zanjir qolganini tashlaydi.

Keng tarqalgan xato: Tor va umumiy shartlarning tartibini tekshiring.

- a: Tor shart umumiy shartdan keyin qolib ketgan.
- b: Yuqori ball birinchi shartni bajaradi.
- c: else if zanjiri faqat birini bajaradi.

## switch-case va to‘liq qamrov

Kursdagi switch mode {case ...; default ...} bir qiymatni aniq variantlar bilan taqqoslaydi. Faqat mos case ishlaydi; avtomatik keyingi case ga o‘tish yo‘q.

default hech bir case mos kelmaganda ishlaydi. Bu psevdokod qoidasi; haqiqiy tilda, masalan C uslubidagi switch da, break va boshqa qoidalarni alohida tekshirish zarur.

Oraliq, bir nechta o‘zgaruvchi yoki murakkab mantiq uchun if ko‘pincha ravshanroq. Menyu kodi kabi aniq diskret qiymatlar switch uchun mos.

### Ishlangan misol

mode = 2; switch mode {case 1: r ← 10; case 2: r ← 20; default: r ← 0}. r?

1. mode ikkinchi case ga teng.
2. Faqat r ← 20 bajariladi.
3. default bajarilmaydi.

Javob: 20

### Mashq — `cond-switch-practice-1`

mode = 9; switch mode {case 1: r ← 10; case 2: r ← 20; default: r ← −1}. r?


Kalit: -1

1. 9 berilgan case lardan biriga ham teng emas.
2. default r = −1 beradi.

Keng tarqalgan xato: Noma’lum qiymatga mavjud case ni taxminan moslamang.

Ishora: Aniq moslik bo‘lmasa default olinadi.


### Mashq — `cond-switch-practice-2`

“x musbat VA y manfiy” kabi shart uchun qaysi usul aniqroq?

- a) Har qanday kirishda default
- b) if (x > 0) AND (y < 0)
- c) switch x da faqat case 1

Kalit: b

1. Shart aniq bitta qiymatga tenglik emas.
2. if ikki taqqoslashni AND bilan bog‘laydi.

Keng tarqalgan xato: switch ni har qanday shartning o‘rniga ishlatmang.

Ishora: Bu yerda bitta kod emas, ikki belgi tekshiriladi.

- a: Bu kerakli shartni tekshirmaydi.
- b: Ikki o‘zgaruvchi bo‘yicha mantiq bevosita yozilgan.
- c: Bu barcha musbat qiymatlarni va y ni qamramaydi.

### Boshlang‘ich tekshiruv — `cond-switch-precheck`

code = 1; switch code {case 1: r ← 4; case 2: r ← 8; default: r ← 0}. Kurs qoidasi bo‘yicha r?


Kalit: 4

1. Birinchi case mos.
2. Keyingi case ga o‘tish yo‘q, r = 4.

Keng tarqalgan xato: Boshqa tilning fall-through qoidasini bu psevdokodga ko‘chirmang.


### Yakuniy tekshiruv — `cond-switch-postcheck`

Menyu faqat OPEN va SAVE kodlarini qabul qiladi. Boshqa kod uchun xabar ham kerak. Nima qo‘shiladi?

- a) Noma’lum kodni SAVE deb olish
- b) OPEN ni yana takrorlash
- c) default da noma’lum kod xabari

Kalit: c

1. Ma’lum variantlar alohida case.
2. Qolgan kirishlar default orqali tushunarli xabar oladi.

Keng tarqalgan xato: Noma’lum kirishni jim qoldirmang yoki boshqa amalga aylantirmang.

- a: Bu noto‘g‘ri amalni boshlashi mumkin.
- b: Takroriy case noma’lum qiymatni qamramaydi.
- c: Mos kelmagan qiymatlar aniq qayta ishlanadi.
