## От псевдокода к Python 3

| Запись II кластера | Python 3 | Смысл |
|---|---|---|
| x ← 4 | `x = 4` | Присваивание |
| x == 4 | `x == 4` | Проверка равенства |
| AND / OR / NOT | `and` / `or` / `not` | Логические операции |
| TRUE / FALSE | `True` / `False` | Логические значения |
| OUTPUT x | `print(x)` | Вывод значения |
| RETURN x | `return x` | Возврат результата из функции |
| for i ← 1 TO 3 | `for i in range(1, 4):` | 1, 2, 3; Python не включает верхнюю границу |
| Блок { ... } | Двоеточие и отступ | Строки блока имеют одинаковый отступ |

Не меняйте местами `=` и `==`. `>` не включает равенство, `>=` включает. В Python `;` в конце строки не обязательна. Простые команды можно разделять `;` в одной строке; сложный блок вроде `for` нельзя просто присоединить к такой строке. В многострочном коде курса каждый уровень отступа — 4 пробела.

```python
total = 0
for x in [2, 3, 4]:
    total = total + x
print(total)
```

Результат 9. `print` вне цикла; при отступе внутрь он будет выводить на каждом проходе. `/` в Python — обычное деление; `//` — частное с округлением вниз, `%` — остаток. Не переносите автоматически правила прежнего псевдокода на отрицательные числа. В примерах деления этого материала числа заданы явно.

## Список, функция и ошибка

В списке `xs = [4, 7]` значение `xs[0]` равно 4, `xs[1]` равно 7. `len(xs)` даёт длину. `[]` — пустой список; индекса 0 в нём нет. `None` — отдельный объект, используемый для обозначения отсутствия значения. `0` может быть существующим результатом; если отсутствие обозначено None, различайте его через `value is not None`.

```python
def double(x):
    return x * 2

result = double(3)
print(result)
```

Результат 6. Заголовок функции заканчивается `:`. `return` завершает вызов с результатом. `print` показывает значение; это разные операции.

SyntaxError — недопустимая структура кода; NameError — неопределённое имя; ZeroDivisionError — деление на ноль; IndexError — несуществующий индекс. Даже без исключений программа может вернуть результат против требования. Последняя строка traceback показывает тип и сообщение, предшествующие кадры — путь вызовов.

## Трассировка значений и pdb

Ручная таблица трассировки показывает значения ПОСЛЕ выполненной строки. Стрелка отладчика, по соглашению этого курса, стоит на ЕЩЁ НЕ ВЫПОЛНЕННОЙ строке. Не смешивайте эти моменты времени.

Локальную учебную копию можно открыть через `python -m pdb exercise.py`. `p x` — показать x, `n` — следующий шаг, `s` — шаг с возможным входом в вызываемую функцию, `c` — продолжить до следующей остановки, `q` — выйти. Перед проблемным местом можно поставить `breakpoint()`. Отладчик не исправляет ошибку сам. Не меняйте значение переменной ради наблюдения.

## Git в отдельной учебной копии

Команды ниже относятся к отдельному учебному репозиторию, который вы создали сами. `file.py` обозначает существующий учебный файл. Для локального коммита Git требует user.name/user.email; можно задать отдельную локальную учебную идентификацию.

```text
git status
git diff
git add file.py
git diff --staged
git commit -m "Fix empty input handling"
```

Working tree — рабочие файлы; staging/index — выбранное состояние для следующего коммита; commit — локальная история. Правка после `git add` не попадёт в коммит без повторного add. `git commit` не передаёт на remote; `git push` — отдельная операция. В этом курсе remote и реальная учётная запись не требуются.

`git switch -c feature` создаёт ветку и переходит в неё. `git switch main` переходит в существующую main. `git merge feature` объединяет историю feature с ТЕКУЩЕЙ веткой. Сначала проверьте рабочее состояние и ветку. Маркеры конфликта не являются итоговым кодом: разрешите по требованию, проверьте, завершите через add и merge-коммит. Слияние без конфликта тоже не гарантирует смысловой правильности.
