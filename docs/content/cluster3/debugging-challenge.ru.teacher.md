# Трёхэтапная задача по отладке

Копия преподавателя — с решениями

[README](README.md)

## Цель

Исправить ошибку наблюдением, гипотезой и регрессией вместо случайных правок.

## Материалы

- Python 3, текстовый редактор; локальная копия exercise.py из debugging-starter.py.txt. Оригинал не менять.

- Столбцы журнала: этап, вход, ожидание, факт, вид ошибки, гипотеза, одна правка, повторный тест, вывод.

## Контракт

- Этап 1: add(a, b) возвращает сумму двух чисел. Входы проверки: (2, 5), (-3, 3), (0, 0).

- Этап 2: discount(price, percent): price >= 0; 0 <= percent <= 100. Цена после процентной скидки. Входы: (200, 15), (200, 0), (200, 100), (0, 25). Валидация за этими пределами не входит в задачу.

- Этап 3: can_borrow(available): available — неотрицательное целое. True, если есть хотя бы один экземпляр. Входы: 0, 1, 2.

## Этапы

1. Сначала наблюдайте синтаксическую ошибку стартового кода. Запишите причину этапа 1, сделайте одну правку и запустите его тесты.

2. На этапе 2 вычислите ожидаемую цену вручную. Запишите расхождение с фактом и проследите операции.

3. На этапе 3 проверьте границы 0, 1, 2. После каждой правки повторите и тесты прежних этапов.

4. В первой попытке подсказка этапа 1: проверьте заголовок функции. На этапе 2 дана только таблица ожидания/факта. На этапе 3 подсказки нет.

5. Если тест снова не прошёл, не повторяйте слепо ту же догадку: запишите новое наблюдение и гипотезу. При необходимости сделайте перерыв или задайте конкретный вопрос.

## Результат работы

- Исправленный exercise.py; заполненный журнал; результаты тестов; краткое объяснение необходимости каждой правки.

## Рубрика

- Причина и факт: 0 — нет; 1 — частично; 2 — для трёх этапов есть вид ошибки и конкретное наблюдение.

- Исправление: 0 — требование нарушено; 1 — только обычный случай; 2 — соответствует всем заданным входам и ограничениям.

- Регрессия: 0 — нет повторных тестов; 1 — отдельные случаи; 2 — повторно проверены и прежние этапы.

- Запись процесса: 0 — нет; 1 — есть правки без причины; 2 — отделены гипотеза, правка и результат. До 8 баллов — подтверждение работы, а не диагностика терпения или личности.
