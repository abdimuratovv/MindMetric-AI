## Контракт

- take(items, limit=2): items — список; возвращает новый поверхностный список первых не более limit элементов. Сами элементы глубоко не копируются. items не меняется. limit — целое >= 0, не bool; отрицательное даёт ValueError, другой тип — TypeError.

- find(items, target, default=None): items — список; возвращает индекс первого совпадения по == с нуля. Если совпадения нет, default. Вход не меняется.

- clip(x, low=0, high=10): в этой лаборатории передаются только конечные int/float; low <= high. Интервал замкнут; ниже возвращает low, выше high, внутри x. low > high — ValueError. Вход не меняется.

- Карточка сравнения версий: только в симуляции 2.0 take(items, *, count=2) требует именованный count. Локальный код выполняет только 1.0.

## Рубрика

- Подтверждение документацией: 0 — догадка; 1 — отдельные ответы; 2 — каждый ответ связан с контрактом.

- Точность: 0 — основные результаты неверны; 1 — частично; 2 — заданные результаты и исключения верны.

- Перенос: 0 — лишь скопирован пример; 1 — часть нового случая; 2 — задания, индекс 0 и граница баллов верны.

- Заметка: 0 — нет; 1 — не хватает версии или ограничения; 2 — достаточно для повторного применения. До 8 баллов — рубрика работы, а не оценка общей скорости обучения.

## Решение преподавателя

- Основные результаты: [7, 8]; [7]; 0; -1; 12. Ошибки: ValueError, TypeError, ValueError.

- Перенос: take(tasks, limit=3) → ["A", "B", "C"]; idx=find(tasks, "A"), idx is not None → True; clip(14) → 10.

- Результат str.split — ["a", "b,c"]. maxsplit=1 ограничивает число разделений, в последнем фрагменте сохраняется остаток текста. Источник: https://docs.python.org/3/library/stdtypes.html#str.split.

- Проверьте, различает ли учащийся значение по умолчанию, смысл лимита, индекс 0 и признак отсутствия. Локальный код нельзя представлять как API 2.0.
